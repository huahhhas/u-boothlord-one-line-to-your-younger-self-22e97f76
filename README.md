# One Line to Your Younger Self

Entry for the [make.fun bounty "One Line to Your Younger Self"](https://make.fun/bounty/u-boothlord-one-line-to-your-younger-self-22e97f76).

## The line

> Stop chasing the girl who ghosted you in tenth grade — marry the one who laughs at your jokes, not the one you have to impress.

## How it works

`main.py` (Python 3.13, standard library only) writes the line to `/output/entry.txt` and prints exactly that line — nothing else. It is fully deterministic.

Run it:

```sh
python3 main.py
```
